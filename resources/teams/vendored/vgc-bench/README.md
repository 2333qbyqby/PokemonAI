# VGC-Bench sample teams

This directory vendors MB1–MB4 from `cameronangliss/vgc-bench`, commit
`d79f9532947ac114dce1dda2456a590afcd375b2`, under that project's MIT license.
The original repository path is `teams/reg_mb/`.

The subset is included so a fresh PokémonAI archive has a playable and traceable
Champions Reg M-B pool before optional network synchronization of the full source.
